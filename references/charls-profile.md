# CHARLS 数据库 profile

版本日期：2026-07-19

适用范围：本文件只记录 CHARLS 数据库层面的稳定入口、通用数据特征和跨主题核验要求。它是 profile 层，不是标准流程、主题定义或历史经验汇总。

正式源说明：启用本 Skill 后，本文件的唯一正式位置是 `<SKILL_ROOT>\references\charls-profile.md`。工作区中的同名旧文件不得作为规则依据。

使用边界：

- 本文件用于开工前确认 CHARLS 的数据入口和数据库级核验要求。
- 本文件不保存已完成主题的 raw 清单、最终变量名、公式、阈值、缺失规则、冲突结论、命名历史或用户材料措辞。
- 具体主题的 raw 选择、变量名、分类口径、编码规则和输出结构，以本轮任务、官方问卷详情、raw_codebook、正式定义和过程卡证据为准。
- 如果本文件内容与用户最新要求或官方问卷详情冲突，暂停回报大脑裁决。
- 具体主题证据链留在各主题过程卡 `current_task.md`，不得回填到本 profile 或标准流程正文。

## 1. CHARLS 全局经验

- bookapp 是事实入口；目录检索和官方问卷详情优先于 Easy label。
- 同名变量和近似 Easy label 必须逐年核验题干、取值和目录路径，不得仅凭变量名或标签拼接跨周期来源。
- `997`、`998`、`999` 等高位编码在 CHARLS 中常可能表示不知道、拒答、不适用、缺失或其它特殊选项。遇到时间、频次、金额、时长、计数、总分和连续换算变量时，必须查官方问卷详情、raw_codebook 和 raw 分布，确认它们是特殊编码还是合法真实值；不得机械带入连续计算。普通分类变量也要核查这些编码是否是特殊选项。
